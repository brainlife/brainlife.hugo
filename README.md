## 🚀 Quick start

```bash
npm run dev        # hugo -D server, http://localhost:1313
hugo               # build to public/
```

Pages are in `content/` (`about.md`, `team.md`, `users.md`, `mobile.md`); team and user data in `data/`; images in `static/`.
